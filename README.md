# Quran App

[[License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

تطبيق قرآن كريم - لقراءة وتصفح القرآن الكريم بطريقة سهلة ومريحة.

## المميزات

- تصفح سور القرآن الكريم
- قراءة مريحة وواضحة
- واجهة سهلة الاستخدام
- يعمل على جميع الأجهزة

## التثبيت والتشغيل

```bash
git clone https://github.com/s200077761/quran-app.git
cd quran-app
```

ثم اتبع تعليمات التشغيل الخاصة بالمشروع.

## الاستخدام

افتح التطبيق واختر السورة التي تريد قراءتها.
